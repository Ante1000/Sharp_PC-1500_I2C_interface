Archive - older files of the I2C master for the Sharp PC-1500(A)

The current version is I2C v1.3: installer Basic/pc1500_i2c_installer-v1.3.txt,
test program Basic/pc1500_i2c_arduino_test-v1.0.txt (English), help HELP_arduino_test.md.

pc1500_i2c_installer-v1.0.txt       I2C v1.0, 241 bytes (tested on hardware)
pc1500_i2c_installer-v1.1.txt       I2C v1.1, 252 bytes (simulator only)
pc1500_i2c_installer-v1.2.txt       I2C v1.2, 251 bytes (tested on hardware); use it if the
                                    v1.3 installer shows "USE I2C V1.2"
pc1500_lh5801_flag_test.txt         stand-alone test: do SHL and ROL set the Z flag?
                                    (the v1.3 installer contains the same test)
pc1500_i2c_arduino_test-v1.0_PL.txt the Arduino test program with Polish prompts
                                    (same code as the English version)

All versions use the same memory page, parameters and BASIC calls. Sources and listings:
asm/i2c_v1.0.asm ... asm/i2c_v1.3.asm. History of the versions: README.md.
